# Decisions

Taken with the owner. Do not change them without asking. Add new ones at the bottom with the date.

Guiding principle (owner, 2026-11-14): **the app tracks as little as possible and enforces the minimum set of rules.** It tracks only what the reveal engine, the notes and the AI need. Game rules are shown as text, warnings or optional hints, not enforced.
