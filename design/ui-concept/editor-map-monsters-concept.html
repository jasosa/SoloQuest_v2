Concept: the Monsters tool of the Map tab (right card). Same tokens, cards, rows and buttons as editor-concept.html and editor-tools-concept.html. The right card keeps its place (decision 104). Drawn at 1194 x 834. No em-dashes.

Decided by the owner.
1. Kinds: a list of kind rows, as the Library, because there will be many expansions. Picking a row opens it: the list is replaced by the monsters of that kind, under a header (back button, colour bar, name, count). The kind list scrolls inside the card; a kind with no monster is not listed. 2. After placing: the tool stays in place mode with the same monster picked (as today). Going back to the list does not drop the pick. 3. No "Custom": This quest and My library are kinds. 4. Enemies made in the Library are always under My library, which is always listed, even with 0, because it holds the hint "Make enemies in the Library" (the word Library links to the Library tab). 5. Colours: every bar (kind rows, the open kind header, monster cards) is the colour of the box the item belongs to, as set in My collection (a colour input on each box row of that page; defaults today: base game #6e1f2a, Frozen Horror #3b6b8c). An item with no expansion (This quest, My library) belongs to the base game and takes its colour.

0 · The problem today (from the code)

What the right card lists today. One chip for each of the 9 core monster types (MONSTER_TYPES), then "Custom monsters": every enemy that is not a core type. That is the quest's own enemies (quest.enemyDefs) plus every Library enemy the quest does not have yet (library.addable.enemies, shown with " (library)").
Why Frozen Horror ones are "Custom". The 8 Frozen Horror monsters are Library enemies that come with the box (expansion: "Frozen Horror"). The tool does not look at the box, so box enemies and enemies you made land in the same group.
How a monster is placed today. Pick a chip, tap a square: it is placed (a Library enemy is copied into the quest the first time) and the tool stays on with the same chip picked. Select then a tap picks a placed one.

Pick a monster, then tap a square.

The enemies made in the Library, always listed (decision 4). They are copied into the quest the first time one is placed, and are then also under This quest. I did not draw a dashed "New enemy" card. To make it exact I would have to say what it does: it would open the Library on a new enemy and bring you back, and the editor has no such flow today (the Library is a tab of the editor, new items are made inside it, and nothing returns to the Map tab). So the card shows the hint "Make enemies in the Library", where the word Library is a link that switches the editor to its Library tab, which exists. The Map tab is one tap away when the enemy is made.
