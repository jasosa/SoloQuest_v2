Concept: the editor Map tab, tools and the right card (decided, with Merge rooms worked out). Same tokens, cards, chips, tabs and check box as editor-concept.html. No new colour, font or control. One small state: a title-band button can be pressed (the selection colour, as a picked tab). Drawn at 1194 x 834; variants are half size. No em-dashes.

Decided by the owner.
1. Options: in the right card, which is named after the tool. The left card holds only the tool chips, View and Reference image.
2. Selection: picking a tool clears it. Delete and R work with Select only.
3. Problems: no tab. The "N problems" button in the title band opens the Problems view in the right card (the button shows pressed). There is no Back button: picking any tool on the left, even the one already on, puts that tool's options back in the right card. A tap on a problem row picks Select and selects the thing it names.

What was wrong (checked in the code). Tiles drew its palette in the right card while the other tools used the left card; and picking a tool did not clear the selection, so the last element stayed in the right card.

Merge rooms · how it works today (from the code)

Rule. A merge is a pair of room ids [main, joins] in the quest (areaOverrides, Frozen Horror quest 10: a tile laid over two small rooms). In play the cells of the second room take the id of the first, so the wall between them is gone for sight and reveal, and the second id is no longer a room of the quest: notes, tiles and the start must use the first. The two rooms must touch. A merge is per map of a double quest.
Editor today. The tool has no click on the board. The left card has a help line, one row per merge ("R14 is part of R13" with Split), two room selects (Main room, Room that joins it) and a Merge button. The selects list rooms only (no corridor) and leave out rooms that were merged into another. A refused merge shows a toast "Cannot merge: ..." with one of four sentences (itself, unknown room, already merged into another, rooms do not touch). Merge and Split are each one undo step. The editor board still draws the old wall and both ids.

Merge rooms: decided by the owner.
1. Rooms are tapped on the board; no dropdowns. 2. A merged room is drawn as one outline, a dashed line where the wall was, one id. 3. The first room tapped stays, the second joins it and its id goes. No Swap; Clear empties both slots. 4. A tap on a room that is merged already is refused: "R14 is part of R13. Split it first." 5. Chains are allowed; the list has one row per absorbed room. 6. A tap on a corridor does nothing and says nothing. 7. The merge is refused while a door is on the wall between the two rooms (inline sentence, the button is off). 8. Room ids are shown while this tool is on. 9. Errors are inline in the card, not a toast. 10. Notes, tiles and the start that point at the absorbed id are not rewritten; today's Problems warning stays. 11. The list shows only the map on show.

Summary of the rules

1. Left card: tools, View, Reference image. 2. Right card: named after the tool; with Select the picked element. 3. Picking a tool clears the selection and shows that tool's options. 4. Problems is a pressed title-band button that fills the right card; any tool chip returns to the tool. A problem row picks Select and selects the thing. 5. Delete and R work with Select only. 6. Merge rooms: tap the room that stays, tap the room that joins it, press Merge; the list has Split per absorbed room; a door on the shared wall refuses the merge. All decided.
